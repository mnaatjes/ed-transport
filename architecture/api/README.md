# Interface & Boundary Contracts Governance and Index

Governed by OpenAPI 3.1 and AsyncAPI interface contract standards.

---

## 1. Principles & Quality Gates

1. **Machine-Readable Schemas:** Author contracts strictly in valid YAML/JSON (`openapi.yaml` or `asyncapi.yaml`).
2. **Contract-First Development:** Interface boundaries must be frozen during Elaboration prior to client code generation.
3. **Semantic Versioning:** Interface contracts declare explicit versioning fields matching semantic release tags.
